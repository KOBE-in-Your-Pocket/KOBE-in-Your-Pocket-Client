# アイコンの調整〜保存 手動確認チェックリスト（iOS / Android 実機）

アイコンの位置・大きさ調整（PBI #714）を、実機で選択から保存まで通して確認するための手順書（#721）。
調整画面（`IconCropScreen`）や切り抜き処理（`icon-crop.ts` / `crop-profile-icon.ts`）を変えたときにも使う。

Web はサポート外のため対象外（#738）。

## 準備

- 開発ビルド（dev client）に、18 歳以上で同意済みのアカウントでログインしておく
- [`icon-crop-test-images/`](./icon-crop-test-images/) の画像を端末に入れる
  - **再圧縮しない方法で送る**（USB / AirDrop / `adb push`）。LINE などのメッセージアプリを経由すると EXIF の回転情報が消え、05・07・08 の確認にならない
  - Android（USB デバッグ）の例：
    ```
    adb push docs/icon-crop-test-images/. /sdcard/Pictures/icon-crop/
    adb shell content call --method scan_volume --uri content://media --arg external_primary
    ```
- 画像はすべて同じ図柄：4×4 のマス（列 A〜D・行 1〜4）、四隅が **赤 A1・緑 D1・青 A4・黄 D4**、中央に紫の十字
  - EXIF 付きの画像（05・07・08）は、保存されているピクセルを逆向きに回してあり、回転情報を反映すると他と同じ向きに見える

| ファイル                       | 見た目の寸法 | 備考                                       |
| ------------------------------ | ------------ | ------------------------------------------ |

| 02-landscape-1200x900.jpg      | 1200×900     |                                            |
| 03-small-300x200.jpg           | 300×200      | 拡大の上限が約 1.56 倍                     |
| 04-tiny-100x80.jpg             | 100×80       | 拡大できない（上限 1 倍）                  |

| 07 / 08-exif8・exif3           | 900×1200     | 予備（Orientation 8 / 3）                  |

## 判定のしかた

調整画面で**丸枠の中に見えていたマス**と、決定後の**プレビュー（丸いアイコン）に見えるマス**が同じなら OK。
両方の画面のスクリーンショットを残す。下の「期待する見え方」は、切り抜き計算（`computeIconCropRect`）で求めた範囲から書いている（切り抜き枠の一辺 320pt で計算。結果は枠の大きさによらない）。
